# פיץ׳ — כל שיחות קלוד־קוד במסך אחד

חלון אחד שמראה כל מסוף פתוח: מי עובד, מי ממתין לך, ומה נאמר אחרון.
לחיצה פותחת את השיחה, וכתיבה בו נוחתת במסוף ההוא.

**ועברית שנקראת נכון.** המסוף של אפל מיישם שגוי את האלגוריתם הדו־כיווני,
ולכן מילה לועזית בין שתי מילים עבריות גוררת איתה חלק מהשורה ואתה קורא
את המשפט בסדר הפוך. פיץ׳ מרנדר את אותם הבתים במנוע של דפדפן, שמיישם
אותו נכון. זו כל הסיבה שהוא קיים.

זה נכון גם לערבית, פרסית, אורדו, יידיש, דיבהי וסינדהי.

## ⛔ מה שאין

- **הממשק בעברית בלבד.** אנגלית בעבודה.
- **בלי שרת, בלי חשבון, בלי הרשמה.** הוא קורא את קובצי־השיחה שעל
  המחשב שלך. שום דבר לא יוצא החוצה.
- **קוד־המקור אינו כאן.** המאגר הזה הוא מקום ההורדה ומקום הדיווח.

## Peach — every Claude Code session on one screen

A single window showing every open terminal: what is running, what is
waiting for you, and what was said last. Click a row to open the
conversation; type there and it lands in that terminal.

**And right-to-left text that reads correctly.** Apple's terminal
implements the Unicode bidirectional algorithm incorrectly, so one Latin
word between two Hebrew or Arabic words drags part of the line with it and
you read the sentence out of order. Peach renders the same bytes in a
browser engine, which implements it properly.

Hebrew, Arabic, Persian, Urdu, Yiddish, Dhivehi, Sindhi.

**[Download the latest release →](https://github.com/asafsufush/peach/releases/latest)**

macOS 12 or later · Apple silicon · about half a megabyte · free while in beta.

> ⚠ **The interface is currently Hebrew only.** An English interface is
> being built. Until it ships, this is usable if you read Hebrew.

Source is not published here — this repository is the download and the
issue tracker.
